# CreditScope

Educational probability-of-default modeling with EDA, preprocessing, three classifiers, ROC/PR metrics, calibration, configurable threshold costs, an applicant scenario, and feature influence.

The built-in borrowers are synthetic. An uploaded target can be named `default`, `loan_status`, `target`, `bad_loan`, or `label`.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Never use this demonstration to make real lending decisions.
